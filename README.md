# dnd-combat-master
Builds character sheets and monster stat blocks then uses them to run DnD combat with ease

## Development

Run `npm install`, then use:

- `npm run start:server` to launch the authentication API
- `npm start` to launch the proxied Angular development server
- `npm run start:all` to launch both development servers
- `npm test -- --watch=false` to run the unit tests
- `npm run test:server` to run the authentication API tests
- `npm run build` to create a production build
